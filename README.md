# Neuro Rooms 🧠

Semantic room behavior engine for Home Assistant.

## Instalacja przez HACS

1. Otwórz HACS w Home Assistant.
2. Kliknij trzy kropki w prawym górnym rogu -> **Niestandardowe repozytoria**.
3. Wklej URL tego repozytorium.
4. Kategoria: **Integracja** (Integration).
5. Kliknij Dodaj, a następnie pobierz i zrestartuj Home Assistanta.
